# 宝塔数据库与账号

本项目使用已有的 **MySQL 5.6.x**。宝塔管理数据库服务，Docker 运行游戏；安装器不创建数据库容器，不替换宝塔 MySQL，也不自动重置管理员密码。

## 三种连接不要混用

| 谁在连接 | 地址与账号 |
|---|---|
| 宿主机安装器、宝塔 | 本机 socket 或回环地址，使用本地管理员账号 |
| 游戏容器 | 容器可达的宿主机私网 IPv4，使用 Docker 网段授权的 `game` |
| Windows 晴空后台 | Windows 可达的数据库地址，使用另行配置来源权限的后台账号 |

容器中的 `127.0.0.1` 指向容器自身，不是宿主机宝塔数据库。安装参数 `--db-host` 应填写宿主机可达的私网 IPv4；默认端口为 3306。监听地址、防火墙和 Docker 子网授权都需要匹配。

## 首次安装的管理员连接

交互菜单会探测 mysql 客户端和宝塔安装路径，并隐藏密码输入。命令行安装则需要宿主机上的私有客户端配置，例如 `/root/mysql-admin.cnf`：

```ini
[client]
user=root
password=REPLACE_WITH_YOUR_PRIVATE_PASSWORD
socket=/tmp/mysql.sock
```

```bash
sudo chmod 600 /root/mysql-admin.cnf
```

按本机实际 socket 路径调整，安装时传入：

```text
--mysql-config /root/mysql-admin.cnf
--mysql-bin /www/server/mysql/bin/mysql
```

管理员账号用于版本检查、首次建库和授权；该文件不进入游戏容器，也不提交 Git。只有 MySQL 5.6.x 会通过版本检查。

## 新实例会创建什么

安装器预检已有库与账号冲突，然后建立游戏库和 `qk` 库，创建限定在专用 Docker 子网的 `game` 账号。游戏库清单由[数据库模块](../../scripts/container/database.py)维护。

例如，`--db-allow-host 172.29.86.0/255.255.255.0` 表示允许该 Docker 网段。它不是某台玩家电脑的 IP，也不是需要删掉的重复授权。实际网段以实例配置为准。

现有项目库或账号冲突会阻止首次初始化。重试安装不能靠直接删库解决；已有实例的启动和升级沿用数据库绑定，不重新覆盖建库。

## 数据库账号如何区分

MySQL 账号由 **用户名和来源 Host** 共同确定。下面两个账号可以同时存在：

| 示例账号 | 用途 | 是否由安装器自动建立 |
|---|---|---|
| `game@172.29.86.0/255.255.255.0` | 游戏容器连接数据库 | 按所选 Docker 网段建立 |
| `game@指定公网IP` 或 `game@%` | Windows 后台连接数据库 | 需要另行管理授权 |

MySQL 会优先匹配更具体的来源授权。两个账号可以有不同密码，并访问同一套游戏库；内部账号密码错误时，不会自动换用 `%` 账号的密码重试。

外部后台账号的来源优先限制为管理电脑所需 IP。`%` 表示任意来源，只有明确需要这种连接范围时才设置。后台需要管理账号、角色和物品时，授权范围应覆盖本实例游戏库清单，而不是只给 `qk`；不需要系统库权限或转授权权限。参见[Windows 后台连接](windows-tools.md)。

## 密码与 root 的边界

- 内部运行密码保存在实例 `.env` 的 `GAME_DB_PASSWORD`，必须是 **8 位字母或数字**。旧游戏编码器只处理前 8 位，长密码不能直接用于这一连接。
- Windows 后台的独立来源账号可以使用较长密码。两套密码不同不会影响运行，不需要为了同名而统一。
- 游戏与后台管理使用游戏库账号，不需要 root。root 可以保留管理员权限，但限定为本机登录；收紧前先验证宝塔使用的本地账号和密码，不能在本机还依赖 `root@%` 时直接删除该授权。

安装器不会自动配置外部后台账号，也不会自动收紧 root。这些属于单独的数据库管理操作。修改任一运行密码前，先按[日常管理](daily-management.md#数据库密码与密钥)理解配置来源并做好备份。

## 数据库身份检查

实例保存 MySQL UUID、地址、端口和授权来源。启动、备份时会核对身份，避免连接到另一套数据库。发生绑定不一致时，先核对地址和实例归属；不要删除 `external-database.json` 或修改 UUID 来绕过检查。
