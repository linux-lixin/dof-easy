# 原生客户端配套发布

用途与读者：运维与开发人员。适用范围：dof / native；具体差异见正文。前置条件与操作见正文，执行后核对成功信号；历史证据不代表本次重新执行。

事实来源：[client_reader.py](../../scripts/dof/client_reader.py)。限制和当前验收边界见[当前状态](../status/README.md)。

适用 native 格式 2 / 配方 2.2。原件只在重新派生时需要，正式派生文件已入库；真实读取与完整游戏验收仍待完成，见[客户端状态](../status/native-client.md)。

## 发布范围

当前配方 2.2 已去掉配置中的强制版本字段。仍保留发布元数据版本用于任务隔离，无需用户填写。

当前实现包括 Windows 读取适配的确定性派生器、格式 2 编解码、网页生成端、当前实例材料导入工具和测试。无需替换游戏服务端 ELF、重装游戏、初始化数据库或更换实例密钥。后台更新须按自己的实例部署方式执行。

代码已具备本地测试记录，但实际游戏 DLL 完整读取、控制消息、资源路径及进游戏流程尚未验收。代码合入 main 不表示完整登录链路通过，当前仅用于测试实例联调。详见 [验证记录](../status/native-client.md)。

## 配套更新顺序

1. 拉取 main，记录提交号。核对当前实例的数据库 UUID、游戏公钥 DER 与其 SHA-256、客户端连接地址。继续使用当前实例身份，不能拿其他实例或旧测试公钥代替。
2. 在本机私有目录，用固定哈希的原始配套执行 [部署说明](isolated-admin.md) 中的 `prepare_client_inputs.py`。它派生新 `dof-launcher.exe`、`ijl15.dll`，显式转换模板为新字段，并绑定数据库 UUID、公钥、配方和格式版本。输出是私有网页输入包，不是最终给玩家安装的客户端包；不要提交 Git。
3. 将五文件输入包传到服务器私有目录，运行 `python3 scripts/dof/install_client_inputs.py --instance main --archive /private/client-inputs.tar`。脚本只读核对实时实例身份，不改数据库或密钥。
4. 按 [仅更新 admin 的构建与专用打包](../development/admin-packaging.md) 构建、替换网页容器。构建失败时不替换当前运行容器，不运行 install/init，不重启 game/MySQL。
5. 登录网页，重新导入本实例绑定 PVF、生成新任务，预览并单独应用参数、回读，然后下载同一任务的配套包。旧配方任务不能直接下载或应用，新格式不会自动复用旧发布记录。
6. 关闭测试游戏，把网页下载包安装到完整客户端测试副本，核验清单中的 `dof-launcher.exe`、`dof-client.dll`、`ijl15.dll` 和 PVF。不要只改文件名、只换配置容器或混用旧 DLL。使用普通测试账号完成登录、选角、进城、地下城、返城和重登；装备广播、随机盒及团本另外记录。

### 已存在发布材料时

导入工具故意拒绝覆盖 `.dof-easy/instances/main/runtime/admin/data/dof-client-publication`。如果这里已有旧输入或任务，先停止当前实例的 admin，在同一私有父目录保留旧发布工作目录并改名为明确的旧版本目录，再导入新包；不得删除玩家库、游戏资源、密钥或其他实例目录。不要在运行中的后台直接替换 inputs。输入校验或导入失败时，保持原目录内容，恢复原目录名与对应旧网页镜像。导入成功后再启动新网页镜像。

发布材料切换不会自动更新现有客户端。旧后台不能消费格式 2 输入，新后台也不会静默回退旧协议。回退时必须配套恢复网页镜像和发布工作目录；若已应用游戏参数，需要按网页审计恢复本次字段，不回滚玩家数据库。

## 文件与版本

- 配方：`dof-launcher-reader-2.2`；不再生成或要求 `token_dof_version=2`。
- `dof-client.dll` 是配置容器；`ijl15.dll` 保留实际加载文件名。
- 原件在本机留存，工具按源哈希拒绝未知版本；输出哈希见验证记录。
- 新材料输入绑定实时数据库 UUID，实例名称相同但数据库不同也拒绝使用。
- 生成状态 `READY_FOR_TEST` 不代表游戏验收通过。

## 成功、失败与验收

输入校验、实例绑定、生成任务和逐文件哈希须通过；`READY_FOR_TEST` 之后还要记录匹配读取端的真实消费和玩家流程。失败先保留任务状态与输入恢复点，不重跑初始化；未应用参数的任务不宣称游戏已更新。历史批次检查见[原文档案](../history/clients/format2-update.md)，不作为当前配方 2.2 的完整运行证明。
