# 故障定位

用途与读者：运维与开发人员。适用范围：dof / native；具体差异见正文。前置条件与操作见正文，执行后核对成功信号；历史证据不代表本次重新执行。

事实来源：[manage.py](../../scripts/container/manage.py)；[main-deployment-2026-10-28.json](../validation/main-deployment-2026-10-28.json)。限制和当前验收边界见[当前状态](../status/README.md)。


先确认实例是安装器、手动模板还是隔离测试部署，再查对应状态和日志。故障处理前保存可脱敏的版本、错误码与时间；原始凭据和玩家数据不公开。

| 现象 | 核对与处理 | 恢复信号 |
|---|---|---|
| 远程网页不可达 | 核对 admin 绑定；高级命令默认 127.0.0.1；检查代理、云安全组和端口冲突 | 目标入口返回 200，匿名管理接口仍拒绝 |
| 镜像获取失败 | 核对实例仓库/标签、平台与 offline/build 互斥；不自动回退构建 | 所选模式全部镜像可取，状态显示目标引用 |
| 已有库初始化中断 | 保留卷、实例配置与 UUID，查看初始化日志；不能清库重装 | 原身份与数据完整，服务正常 |
| 原生配置页错误 | 查看能力和结构诊断，区分实例绑定和单个 UI 适配错误 | 受支持模块可读；不伪造缺失表 |
| 查询为空或 409 | 确认视图、字段、结构和实例；当前签到 200 空样本不证明历史原因 | 查询成功及分页标记正确，空不算 populated 验收 |
| 保存后游戏无变化 | 检查执行归属、刷新协议和消费证据；不要反复保存刷回执 | 消费端和实际效果独立验证 |
| Maven package 失败 | 记录插件/证书问题；compile 和专用打包不能宣称标准 package 成功 | 指定构建路径产物可复现且回归通过 |
| 空间不足 | 先核对备份完整性和现用镜像/卷关系；仅清理明确无用对象 | 留出预算余量、健康与保护数据不变 |

不要执行全局镜像/卷清理作为例行修复。当前测试服曾误删现用游戏镜像引用，后从只读快照恢复并重建；过程保留在[部署证据](../validation/main-deployment-2026-10-28.json)，不是推荐升级路径。
