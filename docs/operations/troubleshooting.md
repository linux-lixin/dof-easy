# 排错

- **晴空输入校验失败**：核对固定配套版本、输入清单、12 个二进制及 5 个配置文件。不要改哈希以跳过校验，使用完整匹配原包。
- **已有库或 game 账号冲突**：安装器保护既有数据库。确认实例和数据归属后另行迁移，不能为重试安装直接删库。
- **数据库拒绝连接**：核对 MySQL 5.6 版本、宝塔监听地址、私网地址、3306 防火墙及 Docker 网段授权。管理员密码不应填入登录器。
- **旧模式实例被拒绝**：回到对应旧分支维护；本分支只接受晴空＋外置数据库。
- **密钥不一致**：保留现场并找回同实例的完整密钥副本。不要删除密钥让工具重新生成，这会改变客户端身份。
- **镜像标签不存在**：先使用源码构建；离线安装要求本地已有镜像和等级资源，不会自动下载补齐。
- **容器健康但无法进入游戏**：依次核对原版登录器、公钥、客户端与 PVF、频道端口和公网 UDP。容器健康并不证明完整游戏流程通过。

```bash
sudo bash dof.sh status --instance qingkong86
sudo bash dof.sh logs --instance qingkong86 --service game
```

日志和实例配置可能含私有信息，不提交仓库。参见[端口说明](../reference/ports.md)和[验收边界](../status/README.md)。
