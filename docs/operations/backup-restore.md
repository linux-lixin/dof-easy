# 备份与恢复

```bash
sudo bash dof.sh backup --instance qingkong86
```

备份前核对实例对应的外置数据库身份，使用专用游戏账号导出配置中列出的数据库；包括 `qk`。备份时暂时停止本实例正在运行的游戏服务，完成或失败后尝试恢复启动。输出保存在 `.dof-easy/backups/` 下，具体文件名以命令输出为准。保管完整实例目录及对应数据库备份，私钥、插件配置和密钥副本必须保持同一身份；管理员客户端配置单独保管。实例和备份都不提交 Git。

本分支不提供一键恢复命令。恢复需先停止相关游戏实例，在隔离 MySQL 5.6 中校验备份可导入，再同时恢复对应实例配置、密钥和数据库；禁止把其他实例的密钥与现有玩家库混用。正式恢复前保留现状副本并核对库 UUID、账号授权和数据。重启后检查网关、频道及客户端登录。

当前清理版本没有执行灾备恢复演练，不能把生成备份文件等同于验证完整恢复。参见[验收边界](../status/README.md)。
