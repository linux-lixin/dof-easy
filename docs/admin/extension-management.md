# 扩展管理与资源查询

扩展页面包括原生记录、账号安全、注册限制、资源 ID 校验和功能状态说明。
数据库目标来自后台数据源配置，浏览器不能传入任意 SQL、数据库名或服务器路径。

`DNF_PVF_PATH` 指向只读的实例 PVF，`DNF_PVF_INDEX` 可指定配套索引文件。
索引必须通过版本、长度和来源 SHA-256 核对；缺失或未知的道具名称保留为未核实，不能猜测替换。
部署需要自行配置只读挂载，不把 PVF 或索引数据提交 Git。

管理模式由 `LAUNCHER_MODE=dof/native` 区分，默认 WPF 登录器设置不代表已对原生组件生效。
原生运行记录按已知表结构查询，不提供任意查询入口。
账号和活动的进一步执行等价验收仍需隔离数据库及游戏验证。

S46只读核对当前86级实例：`signin-users` 的结构诊断和第一页接口均返回200，所需字段齐全，取样0行。历史409未复现，旧故障原因仍未证实；空表读取通过不代表有数据时的查询完整性、编码和原工具等价已验证。版本与已验证范围见 [状态页](../dof/status.md)。

记录页的S46修复已完成标准构建和模拟浏览器回归，尚未部署。修改账号、日期、搜索列或文字时，页面清除旧结果并重置第一页，需重新点击查询；不会沿用旧结果的“下一页”偏移。首次可用分类支持文字搜索时，自动选中该分类的默认搜索列。失败提示和结构不兼容继续明确显示，不把失败包装成空列表。见 [S46证据](../validation/admin-record-filter-pagination-s46-2026-10-28.json)。
