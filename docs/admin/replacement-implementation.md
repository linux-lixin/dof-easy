## 免授权输入核对

固定清单为 `metadata/dof/admin-baseline.lock.json`。服务端条目复用既有确定性派生输入哈希，不重新指定另一套原件。原始客户端与派生格式 2 产物使用各自的锁，不能混为同一个文件。

```bash
python3 scripts/dof/verify_admin_baseline.py \
  --server /本地/免授权服务端目录 \
  --tool /本地/免授权覆盖文件目录 \
  --client-archive /本地/客户端文件.zip
```

命令只读取和计算哈希，不执行 EXE、ELF、脚本或覆盖材料。只要一个文件缺失或不匹配，就返回非零退出码。输出不包含绝对路径、密码和数据库连接信息。`sourceVerified` 仅表示材料匹配，不代表菜单审计或游戏验收完成。

## 插件配置管理

入口为 `/admin/dof` 的“团本与插件”。固定模块为 `plugin`、`anton`、`luke`，对应 `plugin.ini`、`anton-raid.ini`、`luke-raid.ini`。

| 接口 | 用途 |
|---|---|
| `GET /api/v1/admin/dof/plugins` | 模块能力、部署配置和不可用原因 |
| `GET /api/v1/admin/dof/plugins/{module}` | 当前字段、文本、编码和版本 |
| `POST /api/v1/admin/dof/plugins/{module}/preview` | 按版本预览字段变更或导入内容 |
| `PUT /api/v1/admin/dof/plugins/{module}` | 保存已经预览的变更 |
| `GET /api/v1/admin/dof/plugins/{module}/history` | 操作历史 |
| `POST /api/v1/admin/dof/plugins/{module}/history/{id}/reconcile` | 核对中断操作 |
| `POST /api/v1/admin/dof/plugins/{module}/history/{id}/restore` | 恢复该操作涉及的字段 |

预览和保存共用 `requestId`、`revision`，并提交 `values` 或导入的 `content`，二者不能混用。恢复使用新的操作编号。所有接口验证管理员权限及数据库实例身份。

变更保留未编辑字段、未知字段、注释及原文件编码。导入只接受当前文件已有的已知字段变更，不使用上传文件覆盖整个原文件。网页导出是 UTF-8 文本；实际保存仍沿用原文件的 UTF-8 或 GB18030 编码。

奖励表、时间、星期、元组和数值在后端检查格式。原模板必须能够完整读回；验证范围不等于原生执行逻辑已通过。自动补全未知配置或直接开放尚未验证的字段不在当前行为内。

每次文件写入先保存 `PREPARED` 恢复记录，再执行完整文件的原子替换，最后标记 `PERSISTED`。写前再次核对原文件哈希；符号链接、重复字段和未知模块拒绝访问。重复请求只返回原结果，不重复改写。恢复只处理原操作涉及的字段，并拒绝覆盖第三方对这些字段的修改。

文件历史保存在该 admin 实例的私有 `plugin-audit/` 目录中，快照不由 HTTP 返回。备份 admin 数据目录时应包含它。

## 部署接线

实例生成模型为启用原生管理的 admin 提供：

- `DOF_GAME_CONFIG_ROOT=/app/game-config`，只挂载该实例的 `runtime/game/data/dof-easy/config/`。
- `PLUGIN_MODE`、`RAID_EXTENSION` 和实际 `LAUNCHER_MODE`，用于显示部署配置；它们不表示已观察到运行效果。
- 既有数据库 UUID、实例绑定和私有管理数据目录。

安装器在配置目录写入 `.admin-instance.json`，绑定实例名和数据库 UUID。接口会同时检查数据库绑定与文件目录标记；挂错其他实例的目录时拒绝访问。既有管理实例再次启动时会核对并补充标记，不覆盖不匹配的标记。

原生登录或启用团本的实例使用绑定后的 admin 入口。启用管理后保存 `DOF_ADMIN_ENABLED=true`，关闭团本时仍可查看和编辑管理配置。为旧通用实例首次添加管理能力时，只执行既有追加式建表和绑定，不重新灌入游戏 SQL 或重置账号。

手动部署必须提供相同的固定挂载、实例绑定及环境变量。仅更新源码不会更新正在运行的镜像或已有部署模型。

保存配置不会开启团本，也不会自动重启游戏。团本当前需要有权限的 GM 使用实例配置中的原生刷新命令；刷新调用与游戏实际效果仍是待验项目。

### S5 固定网页原生刷新

团本配置页新增刷新预览、提交、各频道回执、核对和明确保留当前状态。执行方仍是匹配的 `libdof-plugin.so`；网页只投递安徒恩或卢克的固定配置初始化动作。保存文件、调用原生刷新、四项回读和游戏效果分别展示。回读范围为名称、开放星期、开放时间及最少人数，不据此认定其他配置或整个团本已通过。

| 接口（前缀 `/api/v1/admin/dof/plugins/{anton\|luke}`） | 用途 |
|---|---|
| `POST /runtime/preview` | 持久化两分钟预览，冻结配置哈希、实例、执行器版本、频道启动身份与 dispatcher 线程 |
| `POST /runtime` | 按原编号提交已预览的刷新 |
| `GET /runtime/history` | 操作者、时间、版本快照和逐频道结果 |
| `POST /runtime/{id}/reconcile` | 读取回执；不重新调用原生入口 |
| `POST /runtime/{id}/resolve` | 以新编号明确保留当前状态，关闭未确认任务；不认定原操作成功 |

任务提交前先落盘 `PUBLISHING`，游戏调用前先落盘 `RUNNING`。同编号不重调，包括回复丢失或进程重启；没有完整回执的任务保留待核对。人工保留操作要求原任务已过期、全部频道具有新鲜空闲状态，并检查任务快照版本。一个频道拒绝不会把其他仍在执行的频道提前当作结束。审计保存实际读取的版本及对应执行器哈希，避免历史记录与另一时刻的修订混用。

游戏执行入口位于已核对的 `TimerDispatcher::dispatch` 返回点，实际 dispatcher 线程与进程主线程可以不同。心跳、预览和回执记录并核对线程身份。配置写入和原生执行共用配置目录中的 `.admin-operation.lock`；配置保存结果未核对时不能新提交刷新。文件审计仍保存在 `plugin-audit/`，刷新审计在 `plugin-audit-runtime/`，备份整个 admin 数据目录会包含两者。

安装器为 game 补齐实例身份；只有匹配实例标记、来源哈希和新鲜频道状态时才开放网页刷新。游戏镜像附带自有 i386 流式摘要库及其源码，固定匹配原插件哈希。它通过了真实共享库的 15 个向量和 6 个拒绝场景，且完整原生栈使用的 ELF 哈希与独立验证一致。部署不需要新增容器权限、Docker Socket 或 Gadget 可选摘要接口。改动执行脚本、ABI 或摘要库源码后，须显式执行 `python3 scripts/dof/runtime_apply_contract.py --write` 并重新验证；日常构建可运行同一命令（不加 `--write`）检查版本一致性。

应用和恢复都先持久化预览，再以同一编号、内容、操作者及版本提交。新请求必须携带 `protocol`，旧版页面的无版本请求明确拒绝。配置保存和回读只证明数据库状态，网关、插件读取时机及客户端效果单独验收。原生自动更新、校验开关、服务器 PVF、身份密钥和玩家数据不由这些操作改写。

| 接口 | 行为 |
|---|---|
| `GET /api/v1/admin/dof/client/releases/status` | 当前配置版本、手动模式兼容性及管理协议版本 |
| `POST /api/v1/admin/dof/client/releases/preview` | 记录应用意图和固定来源摘要，不写原生参数 |
| `POST /api/v1/admin/dof/client/releases` | 仅提交原编号已记录且仍匹配的预览 |
| `GET /api/v1/admin/dof/client/releases/{id}` | 原编号状态；仅原操作者的未提交预览可恢复请求内容 |
| `POST /api/v1/admin/dof/client/releases/{id}/restore/preview` | 使用新编号预览字段恢复 |
| `POST /api/v1/admin/dof/client/releases/{id}/restore` | 提交对应恢复预览，保留其他字段并拒绝第三方参数冲突 |
| `POST /api/v1/admin/dof/client/releases/{id}/cancellations/preview` | 以独立编号及记录版本预览取消 |

原生两表沿用锁、私有写前快照和写后核对。普通日志 `PREPARED` 先落盘，私有快照随后落盘，再执行原生写入；核对时没有私有快照可确认未发起原生写入。两处参数部分写入时保留冲突，只有字段仍属于本次前后值才可定向恢复。已经完成的私有回执不会因后续配置变化被改称“未应用”。权限在锁内重新读取，未知结构、触发器和不可见的触发器元数据拒绝写入。

页面将待核对编号、提交标记和取消编号保存于会话存储，不保存参数或整个请求；刷新时从服务器重读固定预览。切换父页面所选配套不能修改待提交内容。具体本地检查及未验范围见 [S19 记录](../validation/admin-script-release-s19-2026-10-28.json)。此处的临时 SQL 配置和模拟页面均不算原 Windows 工具或真实组件验收。
