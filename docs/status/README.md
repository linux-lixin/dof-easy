# 验证状态与范围

截至 2026-11-13，已对私有 Ubuntu 24.04、宝塔 MySQL 5.6.50、86 级晴空配套进行以下检查。运行验证对应[晴空专用版本 167cfa8](https://github.com/linux-lixin/dof-easy/commit/167cfa899d9adb57f152b01c6218df3a96c55e1c)，具体私有地址、密码、密钥与原始日志不在仓库发布。

## 已完成

| 检查 | 结果与范围 |
|---|---|
| 源码与 CI | 183 项单元测试、9 项结构检查、文档检查通过 |
| 游戏镜像 | Linux amd64 源码构建通过，二进制依赖及兼容探针通过 |
| 数据库种子 | 隔离 MySQL 5.6 中验证 q_id 修复、引用保护、幂等性和跨年月表 |
| 实例升级 | 切换至晴空专用镜像，保留数据库 UUID、PVF、密钥与原包配置 |
| 服务端运行 | 网关、两个频道、原版插件加载、数据库连接和密钥一致性检查通过 |
| 公网入口 | TCP 8887、7001、7300、30015、30052 可达 |
| 后台数据库权限 | 外部游戏库账号可登录，账号/角色表读取及零行更新权限检查通过，未修改玩家数据 |
| root 来源限制 | 私有实例 root 仅本地连接，公网正确密码被拒绝；宝塔本地连接和游戏保持正常 |
| 备份文件 | 归档校验和、SQL、PVF 与密钥存在性检查通过 |

后台账号授权和 root 来源限制是该私有实例单独完成的运维操作，不是安装器自动执行的默认配置。上述结果不能推广到任意原包、所有等级或所有操作系统。
