# 直接端口映射验证

2026-10-26，基线 main `5d4d21e`。仅本地代码与测试，未连接现有服务器。

## 实现

- game 直接发布游戏 TCP/UDP、频道端口及 native 的 TCP 8887；admin 直接发布网页端口到容器 80。
- 外置模式只有 game/admin 常驻，内置模式增加 db。keys 为一次性密钥任务，db-tools 仅外置维护时临时运行。
- 删除当前 Compose 的 netguard、ingress、db-check 及其构建／拉取要求。归档旧网络辅助源码；保留历史证据。
- 外置模式游戏健康检查不轮询 MySQL，首次初始化、配置和备份仍检查绑定目标。内置数据库健康检查保持。
- 移除玩家来源 CIDR 菜单／CLI，改为游戏绑定地址，访问控制交给云安全组。旧实例的 CIDR 值不执行，启动时提示。
- 更新时根据 Compose 项目标签限定目标，停止本实例 game/admin，再删除本实例三个旧辅助容器；不删除卷、数据库、运行文件或其他实例。保存私有配置快照，重复执行可重试。旧 channels.json 在 Compose 解析前重新生成，避免幽灵 netguard 服务。
