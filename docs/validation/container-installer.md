## 一次性虚拟机实测

使用官方 Debian 12 cloud image，核对 SHA-512 后建立独立 32 GiB 写层、2.5 GiB 内存、2 vCPU 的 QEMU TCG 虚拟机；只通过本机回环转发访问。测试密钥、数据库、日志和磁盘镜像留在忽略目录，不提交 Git。

- 缺失依赖安装及第二次复用通过：Docker 29.9.2、Compose 5.6.1、Buildx 0.38.1。
- ext4 上保留已有 32 MiB Swap，补足目标到 128 MiB，验证实际启用、0600 权限、fstab 和重复执行；重启该虚拟机后仍有效。删除工具创建的 Swap 后，原 Swap 保留。测试使用小容量验证机制，未实分配推荐的 8 GiB。
- UFW 关闭和恢复通过，期间 SSH 可重新连接，已发布的测试 HTTP 容器持续可达；重启后状态和 Docker 容器恢复。
- firewalld 首轮实测发现停止时会清理 Docker legacy 链，**该轮失败**。修复后，存在 Docker/第三方 legacy 规则时操作前拒绝，规则及容器 HTTP 保持；在无第三方规则的空测试主机上，关闭及恢复通过。
- 因上述 firewalld 行为，新安装先处理防火墙再安装 Docker。已有规则的主机需保留 firewalld 并按端口放行；恢复若需要启动 firewalld，也先做同样检查。没有通过清空规则、杀进程或重启用户 Docker 绕过限制。

复现脚本见 [主机测试说明](../../tests/integration/installer/README.md)。脚本中的测试容器清理、空引擎重启和 firewalld reload 仅属于一次性虚拟机的测试布置，产品安装器不执行。
