[server-runtime-validation.json](server-runtime-validation.json) 绑定当前原生资源锁，并分开保留本地检查和目标实例证据。[web-integration-validation.json](web-integration-validation.json) 记录网页测试、部署及实际 PVF 结果；[game-adapter-abi-validation.json](game-adapter-abi-validation.json) 保留部署前静态 ABI 原始报告，其 `not run` 只描述当时阶段。先前 70 级本地证据仍保留，不替代 86 级验证。

`releaseReady=false` 保持不变。报告更新不修改二进制或锁文件；但 `package_server.py` 会把报告打入资源包，因此重新打包后的归档哈希应重新计算，不能复用旧包摘要。历史部署摘要只描述当时已核对的实物。

后续验收必须绑定实际程序、镜像、配置读取、网页任务与客户端消费结果。单元通过、文件存在、端口监听、`healthy`、`PERSISTED` 和 `READY_FOR_TEST` 均不能单独证明玩家进游戏成功。
