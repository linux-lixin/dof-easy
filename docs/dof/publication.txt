晴空网页后台：源码发布说明

本分支包含网页 admin 改造、Linux PVF 编码与客户端生成、管理接口、隔离部署及恢复脚本。
玩家使用当前配套晴空启动器；网页负责生成和管理，不使用自有 admin 登录器替代晴空客户端。
本次发布不等于完整替代晴空工具，也不表示游戏验收已经通过。实际游戏验收待完成。

已包含的代码
- 原生 UI 编解码、预设与自定义布局管理、配置预览、版本冲突保护、审计和定向恢复。
- 原生设置、记录查询、账号安全、注册限制、活动和经济管理相关页面及适配代码。
- 流式 PVF 上传、不压缩原生编码、参数上下文、尾部校验、持久化任务。
- 晴空客户端配置与背景生成，五文件配置包或绑定 Script 任务的六文件配套包。
- 隔离参数应用、结果不明时核对、MyISAM 显式锁及字段级恢复。

代码状态与运行状态分开
READY_FOR_TEST 只代表文件校验通过。PERSISTED 只代表配置已保存并回读。
游戏验收由操作者完成；前端不得将上述状态显示成已成功登录。
压缩发布、原生自动更新消费和未完成业务适配继续保留未完成状态。
本分支不会修改现有游戏运行文件，也不执行正式切换。

仓库不包含
任何实际账号密码、服务端身份私钥、数据库快照、玩家数据、测试环境标识、取证转储、
客户端二进制、PVF 原包/产物、发布 ZIP、上传记录、任务目录和真实游戏验收记录。
测试代码保留；捕获的原生对照输入需显式从本地提供，未提供时相应测试跳过。
运行时生成的合成测试输入、测试 RSA 密钥不保存到仓库。

私有输入
配套启动器、ijl15.dll、客户端配置模板、现有服务器公钥由操作者提供到私有 inputs 目录。
QINGKONG_LEGACY_UI_PROFILE 可指向只读挂载的旧版 UI 精确迁移文件；未提供时不开放针对
该旧版快照的迁移。现代 15 种血槽预设和 3 种角色创建预设定义仍随代码提供。
DNF_COMPANION_PREVIEW 可指向本机配套资源预览 JSON；未提供时页面没有导入预览条目，
不会用示例条目冒充玩家实例配置。原生配置表查询仍按当前数据库执行。
以上文件均不应写入 Git 或公开镜像层，应只读挂载到专用数据目录。

构建与测试
Java：可用 Maven 构建，或使用 scripts/dof/compile_admin.py 指定已准备的 JDK/依赖目录。
Vue：services/admin/frontend 中执行 npm ci、npm run build。
Python：python3 -m unittest discover -s tests/unit/dof -p 'test_*.py'。
Java 单元测试：services/admin/backend 下使用 mvn -Dmaven.test.skip=false test；需要外部条件的原生/数据库测试显式启用。
原生捕获输入通过 -Dqingkong.private.fixtures=/本机私有目录 提供；旧 UI 精确迁移测试另需
-Dqingkong.legacy.ui.profile=/本机私有目录/ui-native-100.json。
MyISAM 契约测试需指定 qingkong.contract.properties 与 qingkong.contract.migration；
测试先验证一次性数据库标记、UUID 以及不存在玩家库，不能指向游戏数据库。

部署见 deployment.txt；客户端接口和格式见 protocol.txt。
