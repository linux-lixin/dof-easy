# 晴空兼容资源

本目录只保留 plugins/frida/frida.so，供晴空的数据库凭据适配使用。它不是可选玩法插件；不要删除，也不加载旧 frida.js。

DP2、普通 Frida 玩法脚本、派生 native 登录器/网关与旧团本扩展已移除。原版晴空插件及团本配置由私有输入提供，按[输入清单](../runtime/ubuntu/qingkong/inputs.lock.json)校验。

保留的共享资源仍受[构建锁](../../../metadata/build-inputs.lock.json)校验，第三方归属见[说明](../THIRD_PARTY_NOTICES.txt)。
