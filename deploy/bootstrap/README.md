# 实例密钥初始化模板

用途与读者：维护部署模板的开发者。适用 dof/native 新实例与已存在身份的校验；不在宿主机直接执行脚本。

[init-keys.sh](init-keys.sh) 在初始化容器内消费 `/keys`、`/game` 挂载和 `LAUNCHER_MODE` / `RAID_EXTENSION`。新实例生成 RSA-2048 私钥和公钥；已有密钥须匹配，已有游戏公钥不同则退出，绝不覆盖。native 或团本启用时还校验 `/game/dof-easy/keys`。输出均为私有实例文件，不提交 Git。

前提与顺序：按[部署总览](../README.md)选择同一实例的持久化挂载，先完成数据库准备和初始化再启动依赖服务。成功是初始化容器零退出且公私钥及游戏副本一致；失败保留原身份与卷，核对挂载，不能删除旧密钥重试。模板参数与副作用以脚本为来源。当前完整游戏验收边界见[状态](../../docs/status/README.md)。
